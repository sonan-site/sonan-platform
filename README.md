# منصة مسابقة سنن

منصة تدير رحلة المشارك في مسابقة سنن، ضمن بنية أعمّ تستوعب برامج الجمعية القادمة (مسابقات · متابعة أسبوعية · حفظ عن بعد).

**الراعي:** إبراهيم الحسين — جمعية سنن التعليمية، إدارة المشاريع التعليمية (رجال).
**نمط التنفيذ:** بناء ذاتي بمساعد آلي تحت راعٍ واحد (`docs/adr/0008`).

---

## أين وصلنا — ٣١ أغسطس ٢٠٢٦

**`docs/ENTITIES.md` معتمدة، والحزمة الأولى من البذرة مصبوبة.** المستودع يعمل: `pnpm verify` أخضر، و`pnpm build` ينجح، وخطّاف ما قبل الدفع يمنع دفعاً فاشلاً — **مُجرَّباً بكسر متعمَّد**.

**المرحلة التالية: `س٤` — المادة وحقول الواجب اليومي.** المادة المرقَّمة · مقاطع المسار المتفرّقة · دالتا الرتبة المحلّية · قوالب الأيام.

**تنبيه نطاق:** المرحلة الأولى **لا تُكمل دورة مسابقة** — لا تصفيات ولا اختبار حضوري ولا نتائج (`adr/0022`). تُنتج دورة متابعة حفظ كاملة تعمل.

**غير مُتحقَّق منه:** CI أخضر — لا يوجد مستودع بعيد على GitHub بعد. ملف `verify.yml` مكتوب ويشغّل نفس الأوامر التي تمرّ محلياً، لكن **لم يُشغَّل فعلياً**. يُغلق البند عند أول دفع لمستودع بعيد.

```
✓ ٠ ── الترتيب     المستودع · الهيكل · الوثائق · الدستور
✓ ١ ── الحسم       سبع تناقضات + قرارا 0005/0002 المُعاد عرضهما
✓ ٢ ── التقنية     المزامنة · العزل · الدخول  (وسقطت فجوة تخزين البُنى)
✓ ٣ ── المواصفة    docs/ENTITIES.md  — معتمدة، ٣٩ جدولاً و١٣ قاعدة عمل
✓ ٤ ── الأساس      حزم البذرة ١–٦   (الست مكتملة · ٧ مؤجَّلة بدَين)
  ٥ ── سنن         المرحلة الأولى: س١–س٦
  ٦ ── المسابقة    المرحلة الثانية: س٧–س١٣  (مؤجَّلة · adr/0022)
  ٧ ── التعميم     الحزمة ٧ — استخراج البذرة ووسمها (دَين مسجَّل)

المرحلة الأولى من سنن — بالترتيب:
  ✓ س١ الهيكل الإداري · ✓ س٢ الواجهة العامة · ✓ س٣ التسجيل والقبول
  س٤ المادة وحقول الواجب · س٥ الخطة · س٦ واجهة المشارك والتوليد
```

**خمسة بنود غير حاجبة** مؤجَّلة لمواضعها: الإشعارات · الجوائز · رقم التكرار · الداش بورد العام · سحب الأسئلة.

لا يُقفَز فوق مرحلة، ولا تبدأ مرحلة قبل اعتماد سابقتها — والاعتماد **حدث مؤرَّخ** لا انطباع.

## أين تجد ماذا

| تبحث عن | المكان | حكمه |
|---|---|---|
| قواعد البناء التقنية | `C:\dev\standards\` | **مُلزِم** · لا يُنسخ هنا |
| قواعد العمل داخل المستودع | `CLAUDE.md` | **مُلزِم** |
| معنى أي مصطلح | `CONTEXT.md` | **المرجع الوحيد** للغة |
| لماذا قرَّرنا كذا | `docs/adr/` | **مُلزِم** · لا يُعدَّل محسوم |
| ما لم يُحسم بعد | `docs/open-questions.md` | بوّابة |
| ما أجّلناه بشروطه | `docs/TECH-DEBT.md` | يُراجَع كل جلسة |
| الجداول والحقول | `docs/ENTITIES.md` | هيكل — غير معتمد |
| كيف وصلنا للفكرة | `docs/discussions/` | **مصدر تاريخي** — لا يُبنى عليه |
| ما سُلِّم لطرف خارجي | `docs/requirements/` | **مصدر تاريخي** — لا يُبنى عليه |
| شكل الواجهات | `docs/prototypes/` | محاكاة بصرية |

**قاعدة الفصل:** `CONTEXT.md` و`docs/adr/` **مرجع** يُحتكَم إليه. و`discussions/` و`requirements/` **مصدر** يُقرأ ولا يُبنى عليه. عند التعارض، المرجع يفوز — ويُرفَع التعارض للراعي.
