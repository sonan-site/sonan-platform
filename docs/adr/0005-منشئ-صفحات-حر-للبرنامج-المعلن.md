# صفحة البرنامج المعلن: منشئ صفحات حر، لا نموذج ثابت الحقول

كل برنامج له صفحة هبوط عامة (رابط منشور مستقل) تُبنى عبر منشئ صفحات حر — الإدارة تضيف/تحذف/ترتّب "عناصر واجهة" (نص، مسارات، أسئلة شائعة، قسم تسجيل...) بحرية كاملة لكل برنامج على حدة، لا حقولاً ثابتة الترتيب والنوع يُكتفى بتعبئة محتواها. قرار مقصود بصرف النظر عن الحجم التقني الإضافي مقارنة بنموذج ثابت أبسط — المرونة مطلوبة فعلياً لأن أنماط البرامج المختلفة (مسابقة، متابعة، حفظ عن بعد) تحتاج عرضاً مختلفاً جوهرياً لا يخدمه قالب واحد ثابت.

**البديل المرفوض:** نموذج ثابت بحقول قابلة للتعبئة فقط. أسرع بناءً، لكنه يحدّ من التوسّع لأنماط برامج مستقبلية تحتاج عناصر عرض مختلفة كلياً.
