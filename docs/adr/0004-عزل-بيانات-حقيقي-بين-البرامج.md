# عزل بيانات حقيقي بين بيئات البرامج، لا عزل بصري فقط

عند دخول مستخدم لبرنامج مسجَّل فيه، يدخل بيئة بيانات معزولة تماماً عن أي برنامج آخر — لا مجرد فصل واجهة مع مشاركة خلفية للبيانات. المستوى العام (المتجر، صفحات البرامج المعلنة) يبقى مشتركاً وعاماً بلا عزل، لأنه تسويقي بطبيعته ولا يشترط حساباً أصلاً؛ العزل يخصّ طبقة التشغيل فقط (حفظ، درجات، تصفيات) بعد التسجيل الفعلي.

السبب: أنماط البرامج المختلفة (مسابقة، متابعة أسبوعية، حفظ عن بعد) تحتاج حقولاً وبيانات مختلفة جوهرياً بطبيعة كل نمط — دمجها في بنية بيانات مشتركة غير معزولة يُنتج تلوّثاً حتمياً في أي إحصاء لاحق يشمل أكثر من نمط برنامج معاً.
